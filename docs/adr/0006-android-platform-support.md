# Android 平台支持基线

状态：accepted（2026-10-14，用户明确要求各设计不再适配旧 Android）。

项目所有模块的 Android 最低支持系统统一为 **Android 10 / API29**。Android 9 / API28 及以下不再适配，不作为新交付或验收门槛；不为它们新增兼容分支、旧权限路径或工具链。此规则适用于主客户端、独立组件、原生插件的项目接入要求、设计稿、测试计划与验收清单。`targetSdk`、编译 SDK 与最低支持系统是不同配置，不因提高最低版本而降低 target/compile。

新设计使用 API29+ 的平台行为；例如保存组件向 MediaStore 添加自身图片，不申请旧 `WRITE_EXTERNAL_STORAGE`、不建立 `requestLegacyExternalStorage` 方案，也不因保存而索取全图库读取。确需读取用户媒体的模块采用其支持系统上的最小授权入口，不能把本保存路径无需旧权限推广为所有功能无需权限。某项功能有更高的系统要求时，仍明确能力检查、可用范围与替代动作，不从最低版本推断功能已可用。

本次图片组件示例实际设置 minSdk29 并移除旧权限声明。其他工作分支的运行时代码由其所属任务在接续时核对和落实；本设计决策不声称已修改它们的构建配置或完成回归，不操作其他任务环境、认证服务或设备。

历史构建/验收报告保留当时的 minSdk、设备和结果，不重写为新基线通过。当前设计和后续任务以本 ADR 为准；旧系统场景登记 `SKIP`（用户移除支持范围），不登记 `PASS`。提高最低版本不代证 Android 10+ 所有系统或设备已验收，实际证据仍逐设备、系统、APK 和能力记录。
