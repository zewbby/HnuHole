## 实现

`HnuImageViewerRoute` 保留底页绘制并透明承载查看器，进入淡入、退出不叠加另一段路由动画。帖子/评论、编辑器、私信共用。单指上下拖动使图片跟手移动/缩小，背景及工具栏渐隐；达到距离/同向速度门槛后用220ms顺势完成，短拖回弹，动画完成才通知宿主关闭。正常关闭不渲染“查看已结束”中间帧。深色查看器请求浅色系统状态栏图标。

普通图上下均可退出。长图仅允许起手已在对应边界的方向；阅读回顶同一手势不退出。放大、双指、取消、旋转、后台及撤销保护保留。新增测试发现取消触摸后无新帧可能留下半透明背景，已显式调度复位帧并覆盖回归。

横滑开始时准备即将露出的邻页，已访问页复用本次会话的来源、受限provider和静态帧。缓存最多3页，`width * height`总和不超过`2 * maxPixels`；邻页解码首帧后卸下监听，隐藏动图不持续播放。替换组/关闭/撤销清空缓存，后台清除邻页及未完成读取。不访问保存resolver，不创建磁盘缓存，不清理宿主全局缓存。原有每图资源限制仍适用。
