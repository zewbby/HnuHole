# Telegram 安卓字体配色、列表快捷评论与即时互动

任务 UI-ANDROID-APPEARANCE-01；2026-10-21；分支 `codex/feat/telegram-android-appearance`，基于 main `ddf506a` 的独立 worktree。用户授权实现、构建安装展示、提交 PR 并在验证通过后合并；正式服务部署不在本次范围。

## 实现

- 根据用户 Telegram Android 截图校准共享浅色主题：纯白表面、接近黑色正文、中性灰次文字、亮蓝主要按钮及链接蓝；根 MaterialApp、Feed 与 PostTheme 共用，保留现有组件几何及页面结构。
- 原宋体弹框特例由本次全局无衬线要求覆盖。打包 Roboto 400/500/700 与独立命名的 Noto Sans SC 字体，避免真机中文回退到用户手写系统字体；许可、版权与字节摘要随资产交付，注册 Flutter 许可证。
- 列表评论图标直接打开“回复给 发帖人”弹框；帖子正文仍打开详情。复用 CommentComposer、帖内身份核对、CommentController 持久任务、未知结果及原失败恢复入口，不新增发送 API。
- 首次未绑定发言身份时选择身份，选择本身不发布，返回弹框再次点击回复提交。绑定身份沿用服务器结果。临时文字按当前列表和帖子隔离，收起保留、离开列表或更换账号清除。
- 先持久写入评论任务，再收起弹框继续后台发送；服务端确认发表后刷新列表／详情共享的评论总数，未确认时不伪增数字。
- 点赞／取消点赞与收藏使用既有乐观状态，不再以转圈替换图标；同帖在途请求串行，连点合并到最后期望状态，点赞与取消立即更新图标和数量。保留 CAS、明确失败回退、未知先核对、账号围栏及迟到响应保护。
