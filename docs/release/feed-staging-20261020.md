## 共享环境操作与维护

本机实际控制入口为 `E:/HnuHole-feed-staging-20261020/runtime/control.py`，通过WSL `python3` 调用，命令 `health`／`stop`／`start`／`recover`。`start`本身不等于解冻；停机后必要时用`recover`以当前authdev原operator显式签名恢复再watch，最后严格TLS核对C/V ready200。不能用数据库UPDATE清除冻结。旧初始化／seed／restore脚本不可盲重跑。

独立未合并CAS候选固定aab1061／C0021/V0004，公有C50649/V41979、独立PG36627/37819、新密钥／CA／账号，仅用于修复回归。配置在同runtime下 `cas-public/`；私有根为原专属根的 `cas-lab/`，源码为 `candidate-source/`，与共享 `lab/` 不混用。其健康／启停／恢复只用 `cas-control.py`；fresh-init旧工具打印“schema18”是历史固定提示，实际Goose/源码与manifest均核为0021，不能按打印文字推断版本。首次夹具调用缺Pillow及公有文件chmod被Windows拒绝均在操作者脚本层修正，沿已持久任务继续，没有重新seed或改业务权限。

停机用入口的quiesce：锁住两侧Gate提交点，按记录的PID/start token停止自有服务与watch，再证明本任务全部PG停止；不杀全局postgres/go，不碰其他chat的设备／ADB／SDK。共享环境为联调保留在线；下一次更新先向两个消费者交接固定SHA、迁移和窗口。

当前测试实例备份使用custom格式（包含SQL媒体bytea），另保留权限SQL、源码、二进制摘要、配置和原Gate材料。恢复时 `--no-owner --no-privileges` 会丢ACL，必须先恢复deny baseline，再跑完整canonical grants；只恢复表而不核权限／主键／清理hook不能上线。备份含秘密，按私有材料保管，不能附到PR。

## 正式发布前必须完成

当前runtime仅支持dev装配，不能把本机配置改个域名就称生产。需要明确生产C/V独立主体、受控配置／密钥与签名、可信授时／独立锚点、正式TLS、运营恢复责任、监控、备份保留与媒体/WAL擦除治理；现有P03/P05全生产证据仍缺失。

维护者授权具体正式环境与发布窗口后，固定**已合并且全部适用CI通过**的后端SHA及签名APK；将前端接线／Android用例与该SHA和迁移版本逐项对应。解决迟到PUT后必须统一使用0021兼容的写入服务，禁止混跑旧写二进制。记录授权人、操作者、版本、时间与Goose版本。

发布窗口先冻结业务写入／停止worker，固定C/V一致恢复点，导出DB、角色／权限清单、配置密钥版本及Gate操作材料；校验备份摘要并先在**独立恢复实例**完整恢复，对表、sequence、媒体、主键、清理hook和受限权限比对。没有成功恢复证据不得迁移正式库。保留旧源码和二进制，应用回滚与DB恢复分别审批。

在受控owner下顺序Goose up到明确目标；V不做无关升级。重授baseline及原启用图片／评论／治理权限，审计runtime无DDL／多余列权限、recovery/business/V无业务读取。停止旧writer后启动统一新binary；显式Gate恢复、旧会话失效处理、严格TLS健康与合成账号smoke通过，才按授权解除维护。记录迁移SQL和二进制摘要、schema版本、回归、失败与恢复动作；不在记录内写秘密。

## 正式故障与恢复决策

- 健康／权限／一致性失败：维持维护和fail closed，保留Gate锚点、DB、请求关联ID、日志及部署记录，先隔离故障。禁止盲目重跑seed、改授权表、删除version表或恢复旧Gate文件。
- 仅应用失败且旧binary已在同目标schema上验证兼容：可按批准回退应用；0021条件写协议不能回退到不推进版本的旧writer。当前无此兼容证明，默认前向修复。
- 0019/0020/0021 Down均拒绝。需要DB恢复时，暂停全部新写，保留事故后快照／WAL，在新实例恢复已校验备份和同一恢复点的配置／Gate材料；重新授权、摘要比对、受限启动、显式签名恢复和正常重登，核对后按批准切换。原故障实例只读保留。
- 恢复旧备份会丢失恢复点后的浏览、偏好、赞藏、评论、发帖与会话事实；必须由维护者决定RPO和补偿，不假称零丢失。不跨C/V恢复不一致时间点，不单独回滚版本／Gate。恢复后复验全部列表、计数、隐私、屏蔽、注销清理与媒体链路。

实际本机全量恢复82项摘要只证明本次合成数据与开发隔离范围；尚无正式环境、跨主机灾备、RTO/RPO或独立运营证明。正式部署等待授权。
