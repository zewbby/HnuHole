## 已确认规则

- 未登录树外壳只提供进入邮箱登录的入口，不提供通道探索。
- 邮箱验证和会话建立成功后请求完整七通道目录；初始露出吐槽、避雷、安利、搭子、情感，互助和科技可探索到达。
- 目录必须完整返回并通过校验才渲染节点；加载中、失败和会话失效分别保留无节点树、提供重试或回到登录入口。
- 目录 API 返回 `id`、不可变 `code`、显示名称、初始展示标记和稳定排序；节点位置、缩放和层次由客户端计算。
- 测试账号 A（A1、A2）和 B（B1）由测试夹具/集成测试初始化器生成；生产迁移只负责表结构和七个通道种子。
