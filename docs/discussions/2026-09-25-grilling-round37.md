# 第三十七轮：匿名标识作用域、密钥轮换与注销处罚（已回答）

状态：2026-09-25。用户进一步收敛稳定匿名标识和账号注销后的处罚语义。

## 用户答复

1. 如果账号只是处于禁言状态，则允许按既有规则申请注销；七天缓冲期内禁言继续生效，正式注销完成后撤销该账号禁言，不延续到同邮箱重新注册的新账号。
2. 稳定匿名标识的服务作用域按推荐：同一邮箱在 Hnuhole 内稳定，但在其他应用或社区中必须得到不同、不可直接关联的匿名标识。
3. 密钥轮换按推荐：协议密钥可以轮换，但不得因此改变用户在 Hnuhole 内的逻辑匿名主体，也不能把已有用户误识别为新用户。

## 最新规则

- **禁言与注销**：禁言不阻止注销申请；缓冲期内仍执行禁言；正式注销完成时旧账号禁言终止，新账号不继承。
- **封禁与注销**：封禁期间不能申请注销；缓冲期内新封禁会取消注销申请。不存在正常业务路径“封禁后正式注销再注册以延续或绕过封禁”。
- **匿名标识恢复**：换机、卸载或清除本地数据后，每次重新验证邮箱都通过隐私协议重新取得同一 Hnuhole 稳定匿名标识，不依赖旧设备长期保存。
- **服务作用域**：稳定匿名标识必须绑定 Hnuhole 的服务作用域；验证方为其他服务验证同一邮箱时，应产生不同匿名标识，避免跨服务可关联。
- **密钥轮换不变量**：换钥只改变协议实现材料，不改变逻辑匿名主体。版本化、迁移、双密钥过渡或其他机制由后续协议设计和安全评审选择。

## 对旧文档的修正

历史档案中“注销后未到期处罚继续”或“需要为封禁设计注销后处罚连续”的表述不再作为当前规则。当前规则以账号模块、管理模块和 ADR 0005 的 2026-09-25 更新为准。
