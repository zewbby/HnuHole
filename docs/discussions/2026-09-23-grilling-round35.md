# 第三十五轮：验证码申请邮箱枚举保护（已回答）

状态：2026-09-23。用户确认验证码申请对新邮箱和已注册邮箱采用相同的对外受理响应，避免普通客户端探测邮箱是否已注册。

## 用户答复

用户按推荐确认：对格式正确的邮箱统一返回“如果可以发送，验证码将到达邮箱”，不区分新用户和老用户；只有输入验证码成功后，服务端才创建或恢复账号。

## 已确认规则

- 邮箱格式及允许域名校验通过后，对客户端返回相同的申请受理状态和通用提示：“如果可以发送，验证码将到达邮箱”。申请响应不区分新用户、老用户或受限账号。
- 邮箱验证码验证成功前，客户端不能获知账号是否存在；成功后才创建新账号或恢复已有账号并建立会话。
- 本轮确认的是对外受理响应和账号创建时点；不据此承诺不同邮箱的实际投递结果、响应时延或限流细节完全相同。
- 响应时延、限流、邮件投递路径和其他侧信道的量化验收继续由 [ADR 0005](../adr/0005-privacy-preserving-email-authentication.md) 的独立安全评审处理。
