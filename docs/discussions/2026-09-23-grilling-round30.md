## 已确认规则

- 首次公开发言前，无身份账号先创建基础身份；已有身份的账号选择一个。只打开身份设置、选择身份或填写输入不绑定帖内身份。
- 账号一旦在某帖完成身份绑定，后续主评论、所有楼中楼回复及从该帖继续发起的互动直接沿用该身份，不再重复设置或提供切换入口。服务端按“账号 + 帖子”执行唯一绑定，拒绝换身份发送。
- 身份设置或选择从发帖、评论、楼中楼回复触发时，保留原操作的文字、图片、通道、标签和回复对象；完成后回到原操作，取消则不发布。
- 主动退出撤销服务端会话并清除安全存储令牌，但保留本机按账号隔离的草稿和文件；未登录或其他账号不可见，原账号重新登录后恢复。
- App 重启或启动恢复收到 `401` 时清除令牌和导航节点，回到无节点邮箱入口，但保留草稿和本地文件；收到 `503` 或超时则保留令牌和本地状态，显示重试，不误判为退出；恢复成功后重新请求并校验完整通道目录。
- 新设备验证成功后接替旧设备。旧设备下一次受保护请求收到 `401`/`session_replaced`，提示“账号已在其他设备登录”，清除令牌和节点，但保留草稿、聊天文件及其他本地账号文件。
- 认证 API 采用：
  - `POST /api/v1/auth/verification-requests`
  - `POST /api/v1/auth/verification-confirmations`
  - `GET /api/v1/auth/session`
  - `DELETE /api/v1/auth/session`
  - 通道目录继续使用 `GET /api/v1/channels`
- 完整邮箱只在认证隔离边界处理，不进入社区业务接口；认证错误按 `401`、`422`、`429`、`503` 分流，并返回机器可读错误码。

## 术语说明

- **帖内身份**：同一个账号在一篇帖子里的固定公开身份。它不是“每次回复临时取的名字”，也不是消息页当前收件身份。
- **账号归属草稿**：本机保存但只属于某个账号的未发布内容。退出后仍在设备上，但对未登录状态和其他账号隐藏。
- **不透明会话令牌**：客户端只保存一串不能直接解读账号信息的令牌；账号和设备状态由服务端保存。
