# 第三十四轮：邮箱与账号不可关联边界（历史答复；枚举规则由第三十五轮补充）

状态说明：本档案记录第三十四轮答复时的讨论快照。其抗枚举议题随后由[第三十五轮](2026-09-23-grilling-round35.md)确认；当前规则以第三十五轮及 AUTH-ENUMERATION-01 为准。

状态：2026-09-23。用户已确认邮箱验证方与社区服务方由不同组织或法律主体控制，使用稳定匿名凭证支持重复登录；任何单一主体不能取得具体邮箱与账号的对应关系，两方主动串通不在保证范围内。邮箱/验证服务不可用时不提供人工恢复，现实身份推断属于独立目标。

## 用户答复

1. 用户按推荐接受邮箱验证方与社区服务方严格隔离，不采用由验证服务保存邮箱匹配标记的单方方案。

2. 用户按推荐接受稳定匿名凭证；它用于在邮箱验证后回到原有效账号，不包含可读邮箱，不作为额外密码或人工恢复凭证。

3. 用户按推荐接受验证服务暂不可用时登录失败并稍后重试，不提供管理员人工恢复、万能验证码或备用密码。

4. 用户澄清隐私承诺指不能知道具体邮箱与具体账号的联系；现实身份是否能从 IP、设备、时间或内容推断另行建模。
5. 用户按推荐接受任何单一主体不可关联的保证，两独立服务主动串通不在保证范围内。
6. 用户按推荐要求验证方与社区服务方由不同组织或法律主体控制，不能只由同一组织内分权代替。

## 已确认决策

- 新增 [ADR 0005](../adr/0005-privacy-preserving-email-authentication.md)，并同步 `AUTH-LOOKUP-01`、进度和交接文档。
- 隐私协议的具体算法、参数、调用顺序、密钥轮换、日志时间关联防护与生产组织尚未设计、实现或评审；候选方案不是已选定实现。
- 认证主链实现须以协议完成独立安全评审为前置条件，不能先做单方 HMAC/邮箱映射再补隔离。

## 后续确认与安全待评审

- 稳定匿名凭证由客户端持有，还是每次邮箱验证后通过隐私协议重新取得。
- 正式注销后创建新账号、旧内容不恢复、未到期处罚仍连续时，使用何种仅社区侧可判定的处罚连续凭证。
- 验证码申请的新旧邮箱统一受理状态和提示已由[第三十五轮记录](2026-09-23-grilling-round35.md)确认；响应时延、限流、实际投递路径等侧信道如何量化验收，仍待 ADR 0005 的安全评审。
