# 第二十九轮：认证主链范围（已回答）

状态：2026-09-23。用户确认下一条开发切片为认证主链，并明确账号创建、身份前置、会话恢复和开发验证码边界。

## 用户答复

1. 认证切片按推荐：邮箱输入、发送验证码、Mailpit 收信、验证、建立/恢复会话、显示通道节点、退出登录。
2. 验证成功后自动创建账号，但不自动创建公开身份。
3. 有效会话在 App 重启后恢复；主动退出清除；会话过期回到无节点树外壳，凭证放系统安全存储。
4. 开发仍走真实验证码流程；Mailpit 查看邮件，开发验证适配器只帮助自动化读取验证码，不提供万能验证码或绕过接口。
5. 没有身份也能看到树和浏览通道；身份只在后续需要公开发言时成为前置条件。

## 已确认规则

- “账号”与“身份”继续分开：邮箱验证创建/恢复账号，会话授权社区访问；公开身份不随账号自动生成。
- 无身份账号可以进入导航树和通道阅读；首次公开发言前再创建或选择基础身份。
- 会话恢复、主动退出、过期回到无节点入口的边界纳入认证切片；验证码规则仍沿用五分钟有效、六十秒获取间隔、三次错误锁定五分钟等既有规则。
- Mailpit 是开发邮件收信工具，开发验证适配器是测试取码边界；二者不改变生产认证规则。
