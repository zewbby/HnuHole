5. 接受推荐的英文词表、冷启动顺序、`200/401/503` 错误边界、OpenAPI 唯一契约和本次登录期间的位置恢复。

## 已确认范围

- API 返回 `id`、不可变英文 `code`、显示名称、初始展示标记和稳定排序；不返回屏幕坐标。
- 未登录请求不授权；目录不完整或请求失败时不渲染部分节点，保留无节点树并可重试。
- 种子数据和 API 的唯一业务来源是服务端数据库；测试账号仍由开发/测试夹具创建。
- 首批自动化验收覆盖七通道唯一性、未授权/已授权 API、加载失败与重试、拖动探索、节点点击和返回位置恢复。
- 英文 `code` 固定为：`vent`、`warning`、`recommendation`、`buddy`、`emotion`、`mutual_help`、`technology`；冷启动前五项的 `initiallyVisible` 为 `true`，后两项为 `false`，排序值为 10 至 70，每次递增 10。
- 目录 API 成功返回 `200`，无效会话返回 `401`，服务暂不可用返回 `503`；OpenAPI 源文件是唯一契约。树位置只在本次登录期间恢复，App 重启或重新登录回到初始布局。
