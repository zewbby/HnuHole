项目统一采用 Feature Branch + Conventional Commits + Pull Request。

- 核心 agent 规则：[AGENTS.md](../../AGENTS.md)。
- 完整贡献规范、操作示例与授权边界：[CONTRIBUTING.md](../../CONTRIBUTING.md)。
- PR 描述：[统一模板](../../.github/pull_request_template.md)。
- 自动检查：[协作 workflow](../../.github/workflows/collaboration.yml)。

原初始化说明中的远端未绑定、固定开发分支、直接推 main 和未经筛选的 git add . 示例已废止。
仓库与分支以每次实际检查为准，既有认证与设备验收规则仍按 AGENTS 和对应任务交接执行。
