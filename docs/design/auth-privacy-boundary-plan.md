# AC03 当前隐私边界核对任务单

日期：2026-10-04。分支：`codex/auth-privacy-handoff`。基线 `faf557db4d74ecb2c202fd1349f1bf8fa64e6133`，保留未提交 AC01／AC02；本任务只覆盖匿名基础收口。

## 三步实施

1. 对照最新 HANDOFF、AC03、数据／API 契约与账号／身份产品规则，分别核对当前 C/V schema 和运行权限、实际公共／内部 DTO 与日志、移动端持久状态和固定端点。登记源文件、事实与限制；历史骨架和尚无业务消费者的要求不冒充当前漏洞。
2. 修复当前范围内可证实的隐私差异，保留数据库／HTTP／客户端负向测试；固定后续业务匿名契约及其验收条件。账号＋帖子绑定、身份对私信及公开内容消费者只固定合约，不在本片实现。
3. 执行现有工具支持的相关静态、SQL／HTTP／客户端及实际进程回归，按被测版本记录证据；同步分模块交接、台账、HANDOFF 与 progress。B02、平台、真实分权／灾备／独立审计继续分别登记。保留历史版本证据，清理本次归属明确的临时环境。

## 核对范围与结束条件

| 边界 | 当前核对对象 | 结束条件 |
| --- | --- | --- |
| 数据与权限 | C 正式迁移 1–12、V 1–4、runtime/recovery grants 与 schema 就绪检查 | C 无验证邮箱或邮箱摘要字段；V 无社区账号、用户名、身份资料和社区会话；主体权限互不访问、运行角色不具恢复／迁移权限。资格槽位的既定共同关联能力如实保留。 |
| HTTP | authprivacyhttp、真实 cmd/api 与 cmd/verifier/runtime | 严格字段／规范编码、本方 requestId/no-store、内部 mTLS、错误无原秘密；本人身份接口归属检查与响应 allowlist；无任意账号身份枚举或邮箱找回入口。 |
| 客户端 | AuthStore/codec/vault、HttpAuthApi、身份与当前通道客户端 | 两侧安装 ID 与请求键分离；固定受信端点；敏感状态仅安全存储及必要流程使用；诊断不得反射错误、响应或秘密。 |
| 后续业务 | B05–B11、媒体／聊天本地清理 | 公开资料、注销占位、帖内绑定、身份对私信、管理／恢复规则固定；未实现调用者与动态证明明确列为 NOT_RUN，不能只称待测试。 |

源码核对和自动化负向测试属于有范围的实现检查，不构成人类独立安全审计或生产批准。具体结果与源文件见 [AC03报告](auth-privacy-boundary-validation-report.md) 和 [后续契约](auth-privacy-business-contract.md)。
