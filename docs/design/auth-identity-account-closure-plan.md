# AC02：整账号正式关闭与身份联动实施任务单

日期：2026-10-04（Asia/Shanghai）。分支 `codex/auth-privacy-handoff`，基线 `faf557db4d74ecb2c202fd1349f1bf8fa64e6133`，保留同工作区 AC01 实现。依据 [匿名收口清单](auth-privacy-closure-checklist.md)、[ACCOUNT-CLOSE-01 / ACCOUNT-RETURN-01](modules/accounts.md) 和 [MASK-01 / MASK-DELETE-01 / PRIVACY-02](modules/identity.md)。

1. **正式关闭生命周期与约束。**沿用账号锁串行化、七天缓冲和 C 最终 Gate 授权。在同一关闭事务中擦除所有活动身份的昵称、头像与改名时间，并写入可信删除时间；账号关闭、凭据撤销、身份墓碑和 RELEASED outbox 必须全部提交或全部回滚。零身份账号允许关闭；已初始化且未正式关闭的账号仍保留至少一个活动身份。累计创建计数、身份归属、已有墓碑和成功／拒绝永久回执不可删除、重置或改写，不伪造用户 DELETE 收据。
2. **独立注销投影与前向升级。**增加迁移 11→12、关闭状态的延迟约束和最低运行版本。修复旧 CLOSED 账号遗留的活动资料时只使用已持久可信高水位，标为升级修复时间，不反推或伪造原关闭时刻；证据不足则拒绝迁移。注销投影仅含当前身份的独立 opaque 标识、统一注销头像与状态，不含账号编号、本体或其他身份关系。公开编号的 UI 格式尚未设计，本片不固定格式，也不增加任意身份查询路由。
3. **回归与交接。**保留零／一／三身份、等待／取消、创建／改名与关闭竞争、冻结／旧代、重试／多 worker、失败回滚、旧新账号不继承和升级源码；在现有专属 WSL／SQL 环境执行完整 Go race／vet 与 R03 实际 C/V 流程，并记录固定源码摘要。同步模块交接、台账、HANDOFF 和 progress，保留历史证据。

身份生命周期变更沿用业务事务的显式 READ COMMITTED；数据库延迟约束拒绝其他隔离级别，防止直接 DML 在旧事务快照中绕过账号串行锁造成聚合写偏差。

影响模块：A08、B02，及共享 Gate／会话／迁移／释放链 A00/A01/A02/A03/A04/A06/A10/A13/P01；跨模块 X02/X06/X07。AC03 未实施；B02 的帖子／评论／聊天投影、本人本地聊天／私人备注／搜索清理尚无完整业务调用者，仍由对应模块落实，不计为本片已集成。Flutter／设备／系统 Passkey 和生产独立运营、灾备、人类审计与本片服务端证据分列。提交／推送／部署按当次授权执行。
