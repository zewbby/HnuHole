## 1. 编码授权与环节

最初的“不要编码，先完成认证隐私架构决策”只约束架构讨论阶段。用户随后“开干”，并明确要求实现校邮确认、退役后的原确认续办及双方 HTTP／mTLS，已授权进入 **Phase E**。A–C 负责规则、协议和数据库／API 规格，D 做规格复核；E 按隔离切片编码和验证。独立运营、人类安全审计及生产验收是上线门槛，不能继续用最初的阶段要求阻断已授权实现。

## 2. 实际交付

| 需求 | 实现与边界 |
| --- | --- |
| 校邮申请 | 精确地址解析，不折叠别名／大小写；空闲与占用邮箱相同受理行为；最新码、等待、设备锁与全地址预算 |
| 邮件副作用 | 独立 HMAC 与 AES-GCM 加密短期任务；持久发送尝试后才 SMTP；同键不重发，DATA 未知不判未发送 |
| 校邮确认 | OTP 消费、唯一邮箱配额、原确认及固定 REG_MSG 同事务；签名在事务外，持久签名后返回资格 |
| 原确认续办 | 永久收据先判定旧槽终态；原绑定独立于临时退役待办，保存原准入桶；不再消费旧码，不清后来的配额 |
| 结果／清理 | GET 不推进副作用，不返回票或身份；原 POST 十分钟重取；永久 EXPIRED 摘要拒迟到重执行；未决退役继续处理，过期不签新票；设备与无引用地址元数据闲置二十四小时后有界清理 |
| 双方 HTTP | V 6 个操作和 C 注册／内部退役 3 个操作；公共与内部处理器分开，严格有界解析、独立请求 ID、无缓存 |
| mTLS | TLS 1.3、实际验证证书链、精确环境／服务 SAN URI、正常域名校验、吊销配置、固定 HTTPS 目标与禁止重定向 |
| 注册密码与回执 | NFC、15–128 码点／输入上限、本地阻止名单与用户名相关弱密码检查；Argon2id 64 MiB／3／4，独立盐、版本及并发上限；ACK 后只读重签不复活 outbox |

代码在 `services/api/internal/authprivacy` 与 `authprivacyhttp`；新增 V 实验迁移 `0002_otp.sql`、`0003_confirmation.sql`。原始 0001 实验 SQL 和生产 Goose 迁移未改；现有 API 主路由没有接入这些处理器。

## 3. 验证证据

从 `services/api` 执行 `sh authlab/run-isolated.sh`：新建可丢弃集群、两侧非超级用户数据库、仅私有 Unix socket；本机合成 SMTP、临时 CA 与真实 HTTPS／mTLS 握手。最终冻结源码运行 `go test -race -count=1 -p 1 ./...` 和 `go vet ./...`，均成功，含 **28 个数据库集成案例**（首条切片 11 个、OTP 8 个、确认／续办 7 个、真实 HTTPS 与数据库联动 2 个）。源码哈希及机器记录见[当前验证记录](../../services/api/authlab/eligibility-http-verification.json)。

工具为 Go 1.27.1／darwin arm64、PostgreSQL 18.6。旧首轮 [verification.json](../../services/api/authlab/verification.json) 固定对应 `c316372`，不改写旧证据。数据库案例缺少实验 DSN 时会明确跳过；本报告的运行实际提供了 DSN 并执行 SQL。

新增数据库与网络证据包含：

- 原发送重试不重复投递、地址配额不改变申请形状，原等待不重置。
- 设备三错锁定且重试不延期；旧码识别不计真错；当前码跨设备／流程十错失效。
- 第三次错误的同键重放保留原锁的真实剩余等待；锁过期后不重计或延锁，结果过期时同步清理短期等待记录。
- SMTP 接受、DATA 后明确拒收及回包丢失分别判定；未知状态不重发、不允许并行新发送；邮件加密材料完成／过期清理；构造后的配置／信任池不受调用方修改影响。
- 二十四小时清理有界执行，不删有效设备锁、配额、未决退役、未知投递或原确认引用；仍有数据的邮箱代次不能重置。
- 原子确认、原票重放、无秘密只读查询，以及 HSM 返回时已释放槽位不能发布旧票。
- 真实退役推送先提交、迟到拉取仍返回 PENDING；原确认继续而不倒退终态。
- 推送后其他请求占位，原续办不能清其新配额；原 OTP 到期后只完成旧退役。
- 完整 HTTPS 发码→确认→持钥开户，初始会话仅第一次返回；重复提交只有一个账号与会话。
- 真 mTLS 收据推送和 ACK，删临时待办后原 POST 仍续办；重复旧收据不清新槽位；ACK 清理后只读重签不重建 outbox。
- 未受信／错误环境或服务身份／吊销证书、错误服务器名及低 TLS 版本拒绝；伪造转发证书头不能认证；202、错误 ACK、重定向不能确认投递。
- 重复 JSON 键、未知字段／query、null／错类型／超限／非规范能力、重复头及不配对 Unicode 转义拒绝；查询与变更网络预算独立。

首轮真实运行发现并修正了 PostgreSQL interval 参数类型推断与 TLS `VerifyConnection` 的检查时机：握手回调验证链和身份，HTTP 层再要求握手完成。复核同时修正了 SMTP 配置外部变更、明确拒收分类及同键限流等待提示；落实独立密钥用途、受预算约束的失败锚点、原窗口不可延长及清理不得取消未决退役。

这些是隔离实现与内部 AI 交叉复核的证据，不是生产安全审计结论。
