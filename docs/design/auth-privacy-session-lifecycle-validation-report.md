# 用户名密码登录与服务端会话管理：隔离实现和验证

日期：2026-09-30。分支：`codex/auth-privacy-handoff`。基线提交：`8d3799aaf457a951a8c18e9bb7c45c343a4c3d64`。本轮在已完成的 Authorization Safety Gate 之后继续实现 C 的隔离服务端切片；未接生产路由或 Goose 迁移。

## 交付范围

| 边界 | 实现 |
| --- | --- |
| 密码校验与主动登录 | 复用注册的 NFC／Argon2id v1（64 MiB、3 次、并行 4）和有界工作池。未知用户名也执行同成本 KDF。校验在 SQL 锁外完成，账号锁内重核验证值、盐、参数及统一凭据版本；旧证明遇版本变化不能建会话。 |
| 唯一移动会话 | 登录的账号、权威限制行、旧会话、无秘密幂等结果与最终 Gate 裁决处于同一事务；递增会话代次，撤旧建新。同设备主动重登也替代旧令牌。最近替代设备仅留一条，不向 HTTP 返回安装标识。 |
| 会话认证／续期 | `GET /api/v1/auth/session`、`POST /api/v1/auth/session-renewals`、`GET /api/v1/auth/devices` 每次锁内复核账号状态、封禁、会话撤销／到期、会话与授权代次，再通过 Gate 最终裁决。剩余不超过七天时同一令牌延至最终可信时间＋三十天；不换令牌或撤销秘密，重复请求不叠加期限。被新机接替的旧 Bearer 返回 `401/session_replaced`。 |
| 主动退出／定向撤销 | `POST /api/v1/auth/session-revocations` 只接收单向 `SessionRevoke` 秘密，对应旧会话的撤销与必要代次推进经 Gate 事务提交。规范秘密即使已撤、过期或被清理都 `204`；旧秘密不能撤掉后来新会话。 |
| 重试与留存 | 登录同键同请求提交后只给 `409 SESSION_CREATED_RETRY_LOGIN`，不重发 token；不同负载冲突，过期结果为 `410`。有界 worker 将 LIVE 结果原位缩成永久无身份墓碑；会话摘要按服务端最终到期加七天清理，最近替代项三十天清理。 |
| HTTP 边界 | 复用 C 独立 HTTPS 公共处理器的严格 JSON、规范能力编码、重复头拒绝、服务端请求 ID、`no-store`、请求体限额和网络预算；新增五个会话端点，未接受 V 的安装 ID、邮箱或资格。 |

## 验证证据

使用临时、私有 Unix socket 的 PostgreSQL 集群与非超级用户 C/V 数据库执行 `sh authlab/run-isolated.sh`；它运行 `go test -race -count=1 -p 1 ./...` 和 `go vet ./...`。单独在 `services/api` 下再次执行这两条命令以记录不带数据库 DSN 时的全模块结果。机器记录见 [`session-lifecycle-verification.json`](../../services/api/authlab/session-lifecycle-verification.json)。所有真实数据库结论均来自隔离脚本，普通未提供 DSN 的 Go 命令不能代替 SQL 验证。

新增测试直接跨越 PostgreSQL 事务和真实 HTTPS：错误密码／未知用户名同形失败、账号锁内凭据变化、登录幂等重试与异负载冲突、并发登录只有一条未撤会话、续期／接替／旧撤销秘密交错仍仅一条当前会话、旧设备 `session_replaced`、设备页最小输出、续期阈值／重复／过期、重复撤销、墓碑及服务端最终到期留存。故障测试在密码计算和账号锁等待期间冻结 Gate，验证真实登录／续期不跨冻结提交；显式推进授权代次后旧 Bearer 不复活，新登录可重新建立会话。HTTP 测试还拒绝重复 JSON、重复或错误能力头、错误认证方案和带体续期。

## 仍需后续切片与生产验收

独立恢复码／Passkey 重设、七天注销、处罚写入和移动端持久登出待办尚未实现。由于注销截止权威表还不存在，实验中 `PENDING_CLOSE` 的主动登录目前 fail closed；正式实现七天注销时须补齐截止前主动登录取消申请、到期 `FINALIZING` 与关闭事务的并发裁决。封禁权威行已供会话认证读取，但处罚写入口还须同账号锁下立即撤销活动会话，不能只更新限制行后让旧 Bearer 在解除封禁时复活。

本切片没有接入生产主路由、生产 Goose 迁移、移动端安全存储或通道目录；旧演示 `public.sessions` 仍不能当作新认证权威。生产还需多副本共享限流、密码名单与 Argon2 容量校准、独立授时与库外锚点、灾备演练、最小权限、双主体运营及具名独立安全审计。隔离通过不等于生产上线批准。
