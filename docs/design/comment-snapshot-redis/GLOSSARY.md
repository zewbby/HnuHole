# 评论分页需求讨论

本表记录本次需求对齐中已确认的评论阅读概念。项目既有账号、身份和发布任务定义沿用源码仓库的领域术语表。

## 阅读与展示

**分页名单**：一次评论阅读所使用的有序评论集合，后续翻页沿用该集合的成员及顺序。
_Avoid_: 评论正文快照、实时评论全集

**临时置顶**：本人本次阅读中刚发表成功的评论在本人当前列表顶部的展示位置，刷新或重新进入帖子后恢复正常排序。
_Avoid_: 管理员置顶、永久置顶、全体读者置顶

**楼层内临时置顶**：本人刚发表成功的回复在所属根评论的回复列表顶部的展示位置，不改变根评论在主列表中的位置。
_Avoid_: 把回复提升为主评论、把所属根评论置顶

**发表成功**：评论发布任务已被服务端确认进入公开发表终态。
_Avoid_: 已点击发送、请求已受理、结果未知
