## 保留的交互规则

图片和文字预览在同一显示角色中等尺寸，按比例缩放并裁切，点开看完整原比例。确认发布立即返回原通道；成功才显示顶部小提示，处理中与失败只在我的帖子中呈现，明确失败保留草稿和亮红叹号。删除确认正文采用较小宋体，按钮保持清晰原字体；确认删除成功直接返回来源页并更新列表，不再出现“帖子已删除”中间页。
