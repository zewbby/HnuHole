## 规则与设计

- 依据[POST-FLOW-01](../modules/post-composer.md)、[TAG-SELECT-01](../modules/tags.md)、[MASK-02](../modules/identity.md)。从上到下为标题、选填标签、发言身份；底部只有固定“确认发布”，不增加正文／图片预览、额外确认或直接发布工具栏。
- 顶部返回“发布确认”，当前通道“搭子”作为上下文，不新增跨通道广场。返回编辑须保留输入与选择；确认后回当前通道、后台发送等行为仍按原规则实现。
- 标题为“周末一起去图书馆”。标签显示“选填”、2/3和两个样例已选词“#自习／#周末”，点击标签区域或加号进入既定底部选择面板；样例不代表从正文自动提取，不增加平台固定分类。零标签仍允许发布。
- 身份区只展示所选头像、昵称“松间”和“用于本次发布”，点击进入本人身份底部列表；不显示内部账号、其他身份归属、“已绑定／已固定”等提前绑定结果。选择不发表，实际受理事务才固定身份。
- 页内不复述技术契约或添加没有确认依据的警示。白色开阔写作流程、细分隔和紧凑选择区延续已定稿编辑页；主动作可辨，不用亮蓝、全页暗色或装饰主题。
