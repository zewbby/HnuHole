## 设计卡与实际复审

- 白色整体框架、黑色标题和正文；暗蓝作者／标签／互动细节，灰色时间、浅灰分隔。保持已选图的分量与清晰度，没有额外装饰或全页暗底。
- 标题左侧两行“周末一起去／图书馆”，松间头像与昵称在右；标题下方小字时间和自习／周末细标签。正文直接阅读，没有编辑页字段标签。
- 四段中文正文完整展示，不作省略或摘要；正文后恰好三张图书馆照片，一行三列、等高且边缘对齐。对应来源feed的3图，不把图片放成标题前大横幅。
- 底部紧凑“评论12”、心形36、五角星收藏，评论收起；右上省略号为更多入口，具体权限及作者删除在F1-21另画。读者头像／昵称语义仍按现有身份与联系规则，不加跨帖身份标记。
- 字体以清晰中文无衬线为目标，正文16–17逻辑像素、行高25–28、段间距16；这是设计目标，PNG尚未代证Flutter实际字号或控件尺寸。宋体规则用于确认／提示弹框正文，本阅读页不机械套用。

实际应用hnuhole-ui-craft、frontend-design、ui-ux-pro-max本地检索、Impeccable Operate参考及imagegen。第一条UX查询`mobile long form content reading typography`返回通用截断和网页行长规则：未将列表省略规则用于帖子正文，也未照搬网页65–75字符宽。一次改写`mobile font size readability text spacing`返回移动端最小16字号与触控间隔建议，只采纳可读字号、非裁切与分离点击区域；网页CSS条目不冒称已执行。

已查看实际PNG：中文正文无明显丢字，标题／作者位置、时间／细标签、三列图片及底部计数均在；未显示发布通知、评论输入或全局底栏。照片与公开来源卡片协调，正式产品头像应由实际同一身份资源统一，生成图片不作为身份数据源。
